🚀 How I Deployed My First Website

By Salman Raza | 3 Nov 2026

Hey guys! Aaj maine apni pehli website ko GitHub Pages pe live kiya, wo bhi sirf apne phone se!

Maine Spck Editor use kiya, GitHub pe code push kiya, aur GitHub Pages se site live kar di.

Phone se coding possible hai - bas daily raat 10 baje practice kar raha hu. Aap bhi kar sakte ho!


Steps:
1. Spck me code likho
2. GitHub pe push karo
3. Settings > Pages > Main branch select karo
4. Site Live!
